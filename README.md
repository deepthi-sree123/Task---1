📌 Data Cleaning – Netflix Dataset

This project focuses on cleaning and preprocessing the Netflix Movies & TV Shows dataset using Python and Pandas.

✔ Tasks Performed

Loaded raw dataset

Removed duplicate rows

Filled missing values (director, cast, country, rating, duration)

Converted date_added to datetime

Standardized column names (lowercase + underscores)

Cleaned text fields

Saved cleaned dataset as netflix_titles_cleaned.csv
